# Report Design System

Commit these decisions once and apply them across all pages.

## Hierarchy

Use a three-level reading path: status, explanation, evidence. Page titles identify the subject; visual titles identify the differentiator or question. Avoid repeating the page title in every visual.

## Spacing

Choose one page margin and one primary gap. Derive all coordinates from them. Align edges across rows and reuse a small set of heights. Reserve a header band before analytical content.

## Color

- Background and surfaces remain neutral.
- One accent identifies focus, selection, or the primary series.
- Good, warning, and bad colors carry stable meanings across pages.
- Color is never the only status cue; add label, icon, or sign.
- Use categorical palettes only when categories must remain distinguishable.

## Typography

Use one family and a restrained scale: page title, section/visual title, body/label, and KPI callout. Do not simulate hierarchy with many font families or arbitrary weights.

## Components

- KPI: value, comparison, unit, period, and optional micro-trend.
- Chart: meaningful title, explicit sort, restrained gridlines, direct labels where practical.
- Table/matrix: analytical columns only, frozen identifier when useful, conditional formatting tied to decisions.
- Slicer: visible only for frequent choices; secondary controls belong in the filter pane.

## Accessibility

Maintain readable contrast at the intended display size. Provide meaningful titles and alternative text. Make tab order follow visual hierarchy and ensure selection states remain visible without relying on hue alone.
